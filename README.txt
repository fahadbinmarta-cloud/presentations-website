العروض التقديمية
موقع لعرض مجموعة عروض تقديمية والتنقل بين شرائح نموذجية.

طريقة التشغيل:
افتح index.html في المتصفح.

قبل التسليم:
- استبدل الاسم وبيانات التواصل والمحتوى التجريبي ببياناتك.
- ارفع ملفات المشروع إلى مستودع GitHub مستقل.
- انشر الموقع عبر GitHub Pages أو Netlify وانسخ رابط الموقع المنشور.
